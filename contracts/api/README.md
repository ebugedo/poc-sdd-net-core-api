# Contratos de API

## Propósito
Este directorio contiene los contratos formales de la API. Estos contratos son el "acuerdo" entre el frontend y backend.

## Archivos

### `openapi.yaml`
Especificación OpenAPI 3.0 de la API. Define:
- Endpoints disponibles
- Request/Response schemas
- Autenticación
- Ejemplos

### `schemas/`
Directorio con schemas JSON/JSON Schema para:
- Request bodies
- Response bodies
- Error responses
