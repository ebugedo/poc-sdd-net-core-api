# Especificaciones del Sistema

## Propósito
Este directorio contiene las especificaciones formales del sistema. Las specs definen **qué** debe hacer el sistema, sin detallar **cómo** se implementará.

## Estructura

### `/domain`
- **Definiciones de dominio**: Conceptos clave del negocio
- **Reglas de negocio**: Restricciones y validaciones
- **Casos de uso**: Flujos de usuario permitidos

### `/api`
- **Endpoints**: Definición de la API REST
- **Request/Response**: Formatos de datos
- **Códigos de error**: Manejo de errores

### `/features`
- **Historias de usuario**: Descripciones en lenguaje natural
- **Criterios de aceptación**: Conditions que deben cumplirse
- **Escenarios**: Happy path, edge cases, errores

### `/glossary`
- **Términos del dominio**: Definiciones compartidas
- **Abreviaciones**: Significado de siglas
