# Architecture Decision Records (ADR)

## Propósito
Este directorio contiene las decisiones de arquitectura documentadas. Cada ADR captura una decisión importante y su contexto.

## Formato de ADR

```markdown
# ADR-NNN: Título de la Decisión

## Estado
[Aceptado | Propuesto | Rechazado | Obsoleto]

## Contexto
[Describe el contexto y la Forces]

## Decisión
[Describe la decisión tomada]

## Consecuencias
### Positivas
- [Consecuencia positiva]

### Negativas
- [Consecuencia negativa]

## Alternativas Consideradas
### Alternativa 1
- Pros: 
- Contras: 

### Alternativa 2
- Pros: 
- Contras: 
```
